Introduction & Overview

What is ASOC Client Dashboard?

The ASOC Client Dashboard is a web-based platform designed to monitor the security posture of systems and devices. It consolidates security telemetry into a unified, intuitive interface, enabling users to examine active security events, detected alerts, vulnerability findings, and incident response workflows.

The dashboard integrates Wazuh as the underlying endpoint security and intrusion detection engine, and DFIR-IRIS as the official digital forensics and incident investigation management platform. Monitored assets comprise security alerts, endpoint device inventories, software vulnerabilities, and formal incident cases.

Key Features

The ASOC Client Dashboard delivers the following primary capabilities accessible via the top navigation bar:

Figure: Navigation Bar (Primary Module Switcher)
Dashboard
Visualizes overall security posture, real-time threat activity, potential impact scores, and immediate mitigation priorities.
Incidents
Tracks security alerts detected by Wazuh rules with both raw chronological and aggregated analytical modes.
Devices
Lists monitored physical and virtual endpoints along with connectivity status, hardware specifications, and OS versions.
Vulnerabilities
Catalogs detected software vulnerabilities across hosts, standard CVE identifiers, and active vs solved remediation statuses.
Incident Cases (Reports)
Provides access to formal investigation reports orchestrated via DFIR-IRIS, forensic audit UUIDs, and PDF export dialogs.
