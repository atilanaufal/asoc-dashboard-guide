Frequently Asked Questions (FAQ)

Find quick answers to common operational questions, account policies, and dashboard troubleshooting scenarios.

Session & Account Inquiries

Why was my session automatically logged out?
Automatic logout occurs due to two security mechanisms:

1. Inactivity Timeout: The platform terminates any idle session after 15 consecutive minutes of inactivity (no mouse motion, keypresses, or scrolling) to prevent unauthorized access on unattended workstations.
2. Single Active Session: If your account credentials are used to sign in from another browser window, tab, or computer, the system immediately revokes the prior active session.
What are the password validation rules when resetting my password?
To guarantee account integrity, newly created passwords must fulfill the following policies:
  • Minimum length of at least 6 characters.
  • Must contain both uppercase letters (A-Z) and lowercase letters (a-z).
  • The new password cannot be identical to the current password.
  • Confirmation password field must match the new password exactly.

Dashboard Data & Filters

What is the difference between Mode Alerts and Mode Incidents?
Mode Alerts displays raw individual log events in strict chronological order, which is optimal for forensic timelines.

Mode Incidents intelligently clusters repetitive events sharing the same (Rule ID, Agent ID, Source IP, Date) into a single consolidated row with a Count frequency indicator. This reduces alert fatigue by up to 90% while preserving attack severity visibility.
How can I filter data for custom or historical date ranges?
Click on the time range filter in the header bar and select Custom. A calendar modal will open allowing you to specify exact Start Date and End Date boundaries, or choose quick presets such as Last 7 Days, Last 14 Days, or Last 30 Days.
What should I do if an endpoint agent displays Offline status?
An offline indicator signifies that the endpoint agent has ceased communication with the server. Verify:
  • Whether the target physical or virtual host is powered off or rebooting.
  • Whether local network or outbound firewall rules permit agent communication.
  • Whether the Wazuh agent background service is actively running on the endpoint.
  • Inspect the Last Seen timestamp column in the Devices table to determine when connectivity was lost.
How can I export and print official incident reports as PDF?
Navigate to the Reports module, select a report row to view the detail drawer, and click "Read Full Report". In the full report modal, click the "Download PDF" button. The browser print interface will open pre-configured with professional A4 portrait layout ready to save or print.
